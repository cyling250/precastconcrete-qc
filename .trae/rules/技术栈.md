# 技术栈

## 编程语言
- **Python 3.10+**（项目要求 >=3.10）

## 核心依赖
| 依赖 | 版本 | 用途 |
|------|------|------|
| Open3D | ~0.19.0 | 点云读写、可视化、体素滤波 |
| NumPy | ~2.4.0 | 数值计算 |
| pygmsh | latest | 三维网格生成（混凝土实体的面环/体） |
| PyVista | latest | 网格可视化 |

## 架构分层

### 1. 拟合层 (fit/)
- `k_means.py` — K-means 聚类（基于点云坐标+特征权重）
- `neighbor_features.py` — 基于邻域的特征值指标（线性度、平面度、球度等）
- `fitters.py` — 高层调用：concrete_fit → RansacPlaneFitter, rebar_fit → RansacLineFitter
- `get_part.py` — 按聚类标签提取混凝土/钢筋子点云

### 2. 几何层 (geometry/)
- `BasePoint`, `BaseLine`, `CrossLine`, `SegmentLine`, `BasePlane` — 几何基元
- 投影、相交、内点判定等几何运算

### 3. 模型层 (models/)
- `RansacPlaneFitter` — RANSAC 平面拟合
- `RansacLineFitter` — RANSAC 直线拟合
- `AdjKMeans` — 自适应 K-means

### 4. 重建层 (rebuild/)
- 混凝土交线/交点计算 → pygmsh 面环 → 三维体网格
- 钢筋圆柱参数提取 → pygmsh 圆柱体网格
- 输出 VTK 格式

### 5. 工具层 (utils/)
- 噪声模拟、特征值计算、格式转换、可视化辅助
