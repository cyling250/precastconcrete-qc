# 技术栈

## 编程语言
- **Python 3.10+**（项目要求 >=3.10）

## 深度学习框架
| 依赖 | 版本 | 用途 |
|------|------|------|
| PyTorch | >=2.0 | 深度学习框架, 模型训练 |
| CUDA | >=11.8 | GPU 加速训练 |

## 核心依赖
| 依赖 | 版本 | 用途 |
|------|------|------|
| NumPy | ~2.4.0 | 数值计算 |
| Open3D | ~0.19.0 | 点云可视化 |
| Rich | latest | 进度条、控制台日志 |
| SciPy | latest | PCA、空间搜索 |

## 架构分层

### 1. 算法库 (lib/pointnet2/)
- `model.py` — PointNet++ 模型 (Set Abstraction + Feature Propagation)
- `pointnet_model.py` — PointNet 原始模型 (MLP + 最大池化)
- `pointmlp_model.py` — PointMLP 模型 (残差 MLP + 几何仿射)
- `pointnext_model.py` — PointNeXt 模型 (改进版 PointNet++)
- `dataset.py` — 数据加载器 (NPZ 加载 → 随机采样 → 归一化)
- `metrics.py` — 评估指标 (IoU, Precision, Recall, F1, Accuracy)

### 2. 实验层 (experiments/)
- `_common.py` — 共享训练模块: 种子设置、常量定义、训练/验证循环、损失函数
- `experiment_*.py` — 独立可运行的实验脚本
- 每个实验对应一种配置组合 (架构/损失函数/数据策略)

### 3. 数据层 (mock/)
- 合成点云数据 (NPZ 格式: points + labels)
- 数据生成器 `generate_synthetic_dataset.py`
- 预览工具 `preview_mock.py`

## 损失函数
| 损失函数 | 用途 |
|----------|------|
| `PerSampleWeightedCE` | 默认损失函数，每样本自适应加权交叉熵，处理钢筋(≈2%)类别不平衡 |
| `CrossEntropyLoss` | 固定权重交叉熵 (消融实验中使用) |
