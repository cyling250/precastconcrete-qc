## 架构分层 (三层)

### 1. 骨架模型库 (lib/backbones/)
四种骨干架构统一接口：`Model(num_classes=K, in_channels=C)` → `forward(xyz, geo_features=None, scale=None)`

| 模型 | 文件 | 特点 |
|------|------|------|
| PointNet++ | `pointnet2.py` | SA(SetAbstraction) + FP(FeaturePropagation)，球邻域查询，固定/自适应半径 |
| PointNet | `pointnet.py` | MLP + 最大池化全局特征，拼接局部+全局 |
| PointMLP | `pointmlp.py` | GeometricAffine + ResMLP 残差块，k-NN 邻域 |
| PointNeXt | `pointnext.py` | PointNet++ 改进版，可配置 feature_type (dp_fj/fj/dp/df) |

基础构建块在 `_base.py`：
- `SetAbstraction` — FPS + BallQuery + Grouping + MLP + MaxPool
- `FeaturePropagation` — 距离加权插值 + 跳跃连接 + MLP
- `FocalLoss` / `PerSampleWeightedCE` — 专用损失函数
- `GatedPointNetPlusPlus` — PointNet++ 门控变体

### 2. 级联管线方法 (lib/cascade/)
| 模块 | 功能 |
|------|------|
| `filter.py` | **自适应体素降采样** — S1预测为混凝土的点做4cm体素降采样，噪声+金属全部保留 |
| `stage2_model.py` | **S2模型** — PointNet++ 6ch输入 (XYZ + S1_probs) → 4类输出 |
| `precompute.py` | **S2预计算** — S1冻结推理 + 过滤 → 磁盘缓存 (训练/验证/测试) |
| `validate.py` | **全管线验证** — V2全管线 (S1实时→S2) + S2缓存版验证 |

### 3. 共享工具集 (lib/utils/)
| 模块 | 功能 |
|------|------|
| `common.py` | 全局常量 (设备/学习率/标签/路径)、种子、标签映射 |
| `datasets.py` | **GpuCachedTrainLoader** (物理球查询+GPU缓存+pos_ratio=0.8)、**RandomValDataset** (固定种子)、**RandomSampleDataset** (纯随机消融) |
| `metrics.py` | IoU / Precision / Recall / F1 |
| `training.py` | 泛型 `train_one_epoch` / `validate_one_epoch` (forward_and_labels_fn 插拔) |
| `history.py` | 历史记录模板、JSON/NPZ 持久化、Checkpoint 保存/加载/续训 |

### 4. 点云生成器 (lib/pointcloud_generator/)
`python -m lib.pointcloud_generator [--type|--all|--batch]`

| 模块 | 功能 |
|------|------|
| `_builder.py` | 7种构件 builder (矩形柱/L形柱/矩形梁/T梁/矩形叠合梁/T叠合梁/L叠合梁) |
| `_concrete.py` | 混凝土棱柱采样、端面挖孔、表面粗糙度 |
| `_config.py` | 标签体系、构件几何参数、采样密度、噪声参数、套筒/钢筋规格映射 |
| `_dataset.py` | 批量数据集生成器 (多进程, 6:2:2划分) |
| `_geometry.py` | 多边形操作、圆柱采样、法线估计 |
| `_noise.py` | 5种噪声: 高斯抖动 / 随机缺失 / 离群簇 / 边缘噪点 / 遮挡缺失块 |
| `_rebar.py` | 纵筋生成 (截面顶点→沿轴向)、箍筋生成 (矩形环/多边形环, 支持轴向参数) |
| `_sleeve.py` | 灌浆套筒生成 (圆柱壳+底部+内壁, 支持轴向参数) |

### 5. 实验层 (experiments/)
| 类别 | 数量 | 说明 |
|------|------|------|
| 级联管线基线 | 2 | Phase 1 (S1) + Phase 2 (S2)，支持 --arch CLI 切换4种骨干 |
| 消融实验 | 3 | A1a (纯随机采样) / A1b (无正样本平衡) / A2 (单阶段4类) |
| 敏感度分析 | 4 | S1 (球查询半径) / S2 (体素大小) / S3 (点云密度) / S4 (噪声水平) |

训练器 (`_s1_trainer.py` / `_s2_trainer.py` / `_a2_trainer.py`) 封装独立训练逻辑，通过 `forward_and_labels_fn` 插拔机制与泛型训练循环解耦。

## 损失函数
| 损失函数 | 用途 |
|----------|------|
| `CrossEntropyLoss` | S1 和 S2 标准损失函数 |
| `CrossEntropyLoss(ignore_index=-1)` | S2 训练时忽略混凝土 (label=1→-1) |
| `PerSampleWeightedCE` | 逐样本动态加权交叉熵 (遗留) |
| `FocalLoss` | Focal Loss (遗留) |

## 标签体系 (4 类)
| 标签 | 类别 | 颜色 | S1 映射 |
|------|------|------|---------|
| 0 | 噪声/背景 | 蓝 | 0→噪声 |
| 1 | 混凝土 | 灰 | 1→混凝土 |
| 2 | 钢筋 | 红 | 2→金属 |
| 3 | 灌浆套筒 | 黄 | 2→金属 |

使用场景：
- **S1 (Phase 1)**: 3 类 (噪声/混凝土/金属)，`map_labels(lbl)` 将 label 2/3 统一映射为 2
- **S2 (Phase 2)**: 4 类 (噪声/混凝土/钢筋/套筒)，训练时 ignore_index=-1 跳过混凝土
- **消融 A2**: 4 类直接分割 (单阶段，不级联)

## 构件类型 (7 种)
| 构件 | builder 函数 | 截面 | 轴向 |
|------|-------------|------|------|
| 矩形柱 | `build_rectangular_column` | 矩形 | Z (竖直) |
| L 形柱 | `build_l_shaped_column` | L 形 | Z (竖直) |
| 矩形梁 | `build_rectangular_beam` | 矩形 (水平) | X |
| T 形梁 | `build_t_beam` | T 形 (水平) | X |
| 矩形叠合梁 | `build_rectangular_composite_beam` | 矩形 (水平, 含叠合层) | X |
| T 形叠合梁 | `build_t_composite_beam` | T 形 (水平, 含叠合层) | X |
| L 形叠合梁 | `build_l_composite_beam` | L 形 (水平, 含叠合层) | X |

所有构件支持 `variant="rebar"` (纵筋 + 箍筋) 或 `variant="sleeve"` (套筒 + 箍筋) 两种配筋方案，各 50% 生成。

## 数据文件命名
`Mock_{构件类型}_{编号}_{配筋方案}_{噪声等级}_{密度等级}.npz`

示例：`Mock_t_beam_001_rebar_high_medium.npz`

## 参数管理
项目有两处参数配置：
1. **`lib/pointcloud_generator/_config.py`** — 点云生成器参数 (构件几何/密度/噪声/套筒规格映射)
2. **`lib/utils/common.py`** — 训练超参数 (学习率/batch size/epoch数/路径)

通过 `experiments/_config.py` 的 `ARCH_REGISTRY` 管理支持的架构列表。
