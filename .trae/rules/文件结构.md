# 项目文件结构

```
precastconcrete-qc/
├── .trae/rules/              # 项目规则与文档
├── .vscode/                  # VSCode 配置
├── docs/                     # 参考资料 (PDF)
├── experiments/              # 实验脚本
│   └── experiment_pointnet2_baseline.py  # PointNet++ baseline 实验
├── lib/                      # 算法库
│   └── pointnet2/            # PointNet++ 分割模块
│       ├── __init__.py
│       ├── model.py          # PointNet++ 模型 (SA/FP 层)
│       └── dataset.py        # 数据集加载与预处理
├── mock/                     # 合成点云数据
│   ├── generate_synthetic_dataset.py
│   ├── preview_mock.py
│   └── res/point/            # 生成的 NPZ 数据文件
│       ├── augmented/        # 增强数据 (训练/验证用)
│       └── original/         # 原始干净数据 (验证/测试)
├── checkpoints/              # 模型训练输出 (自动创建)
├── .venv/                    # Python 虚拟环境
├── .python-version
├── pyproject.toml
└── .gitignore
```
