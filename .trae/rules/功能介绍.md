# 功能介绍

## 项目目标

从预制混凝土构件的**点云数据**出发，使用级联深度学习分割管线，自动将点云分为**噪声、混凝土、钢筋、套筒**四类。方法核心为两阶段设计：
1. **S1 (粗分割)**: 3 类 (噪声/混凝土/金属)，钢筋+套筒合并为"金属"
2. **S2 (精分割)**: 4 类 (噪声/混凝土/钢筋/套筒)，仅修正非混凝土类别

## 方法贡献

### 1. 正样本驱动的局部块采样 (Pos-balanced Patch Sampling)

训练数据加载器 `GpuCachedTrainLoader` 的核心创新：
- **物理球查询** (R=150mm ball query) 替代纯随机全局采样
- **非重叠采样** (每个点只被采样一次，最大化数据利用)
- **正样本平衡** (`pos_ratio=0.8`) —— 80% 的训练 patch 包含钢筋或套筒，确保模型在少数类上有足够训练信号

消融对比：纯随机采样会导致绝大多数 patch 为纯混凝土（混凝土占 ~90% 点），模型永远看不到钢筋/套筒，分割效果大幅下降。

### 2. 级联自适应体素降采样 (Cascade with Adaptive Voxel Downsampling)

核心洞察：**混凝土占点数最多 (≈90%) 但最容易分割，钢筋/套筒占点最少 (≈2%) 但最难分割。**

```
S1 (3类) → 仅对混凝土做 4cm 体素降采样 → S2 (4类精分割)
           噪声+金属全部保留 ✓
```

- S1 首次推理 → 标记每个点为噪声/混凝土/金属
- **仅对 S1 预测为混凝土的点**做 4cm 体素降采样（减少 ~90% 混凝土点）
- 噪声和金属点**全部保留**（不丢失稀有类信息）
- S2 训练时 `ignore_index=1`（混凝土不参与梯度），全部容量集中在修正噪声/钢筋/套筒
- 最终预测：混凝土继承 S1 标签，其他类取 S2 输出

## 级联管线流程

```
Phase 1 (S1)                    Phase 2 (S2)
  3 类分割                       4 类精分割
噪声/混凝土/金属              噪声/混凝土/钢筋/套筒
                                │
输入: XYZ (3通道)             输入: XYZ + S1概率 (6通道)
PointNet++ 固定半径            PointNet++ 固定半径
CrossEntropyLoss               ignore_index=1 (不训练混凝土)
                                │
                                ▼
                            S1 预测 → 混凝土 4cm 体素降采样 → S2 预测
                            最终: 混凝土取 S1 标签, 其他取 S2 预测
```

## 实验体系

### 级联管线基线 (--arch CLI 支持四种骨干)

通过 `--arch` 参数选择 S1 骨干网络，验证级联方法的架构通用性：

| 命令 | S1 骨干 | S2 模型 |
|------|---------|---------|
| `experiment_phase1_baseline.py` | PointNet++ (默认) | — |
| `experiment_phase1_baseline.py --arch pointnet` | PointNet | — |
| `experiment_phase1_baseline.py --arch pointmlp` | PointMLP | — |
| `experiment_phase1_baseline.py --arch pointnext` | PointNeXt | — |
| `experiment_phase2_baseline.py --arch pointnet++` | 加载对应 S1 | PointNet++ (6ch) |
| `experiment_phase2_baseline.py --arch pointnet` | 加载对应 S1 | PointNet++ (6ch) |

S2 固定为 PointNet++（6 通道输入：XYZ + S1_probs）。

### 消融实验

| 实验 | 验证模块 | 做法 | 评价指标 |
|------|---------|------|---------|
| **A1a** | 正样本局部块采样 | 纯随机采样 (`random_sample=True`)，只训 S1 | S1 mIoU |
| **A1b** | 正样本平衡 | `pos_ratio=1.0` (自然分布)，只训 S1 | S1 mIoU |
| **A2** | 级联降采样管线 | 单阶段 4 类 PointNet++ (不级联) | 4 类 mIoU |

### 敏感度分析

| 实验 | 敏感参数 | 扫描范围 | 方法 |
|------|---------|---------|------|
| **S1** | 球查询半径 | 100 / 150(基线) / 200 / 300 mm | 重新训练 S1 |
| **S2** | S2 体素大小 | 20 / 40(基线) / 80 mm | 重新训练 S2 (S1 固定) |
| **S3** | 点云密度 | low / medium / high | 评估基线 cascade |
| **S4** | 噪声水平 | low / medium / high | 评估基线 cascade |

## 默认实验配置

| 参数 | 默认值 |
|------|--------|
| 每样本点数 | 8192 |
| Batch size | 16 |
| 优化器 | AdamW (lr=1e-3, wd=1e-4) |
| 学习率调度 | Cosine Annealing |
| S1 训练轮数 | 120 |
| S2 训练轮数 | 80 |
| S1 损失函数 | CrossEntropyLoss |
| S2 损失函数 | CrossEntropyLoss (ignore_index=-1) |
| SA1 半径 | 0.2 (归一化, 固定) |
| SA2 半径 | 0.4 (归一化, 固定) |
| 局部块半径 | 150mm (物理空间) |
| S2 体素大小 | 40mm (4cm) |
| 正样本比例 | pos_ratio=0.8 |
