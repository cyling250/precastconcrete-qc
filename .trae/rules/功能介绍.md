# 功能介绍

## 项目目标

从预制混凝土构件的**点云数据**出发，使用深度学习分割方法（PointNet++），自动将点云分类为**噪声、混凝土、钢筋**三类，支持分割效果可视化和定量评估。

## PointNet++ 分割方法

### 方法流程

```
原始点云 (NPZ: points + labels)
  │
  ▼
1️⃣ 数据加载:
   ─ 从 augmented/ 加载 NPZ 文件
   ─ 随机采样至 8192 点
   ─ 归一化到单位球 (记录 scale)
  │
  ▼
2️⃣ PointNet++ 编码器:
   ─ SA1: FPS 512 点, 80mm 球查询, MLP[32,32,64]
   ─ SA2: FPS 128 点, 160mm 球查询, MLP[64,64,128]
   ─ SA3: 全局, MLP[128,256,512]
  │
  ▼
3️⃣ 解码器:
   ─ FP3: 距离加权插值 + 跳跃连接 → MLP[256,256]
   ─ FP2: 距离加权插值 + 跳跃连接 → MLP[128,128]
   ─ FP1: 距离加权插值 + 跳跃连接 → MLP[64,32]
  │
  ▼
4️⃣ 分类头:
   ─ Conv1D → Dropout(0.3) → Conv1D → 3 类输出
  │
  ▼
5️⃣ 输出: 每点分类概率 (噪声/混凝土/钢筋)
```

### 关键特性

- **动态物理半径**: 传入 scale (mm) 将 80mm/160mm 物理半径映射到归一化空间
- **Dice Loss / CrossEntropyLoss**: 处理钢筋混凝土点云的类别不平衡 (钢筋≈2%)
- **随机采样**: 训练/验证统一用 8192 点随机采样，无预处理流水线

### 实验配置

| 参数 | 默认值 |
|------|--------|
| 每样本点数 | 8192 |
| Batch size | 8 |
| 优化器 | Adam (lr=1e-3) |
| 学习率调度 | Cosine Annealing |
| 训练轮数 | 80 |
| SA1 半径 | 80mm (物理) |
| SA2 半径 | 160mm (物理) |
