# 功能介绍

## 项目目标

从预制混凝土构件的**合成点云数据**出发，使用级联深度学习分割管线，自动将点云分为**噪声、混凝土、钢筋、套筒**四类。方法核心为两阶段设计：

1. **S1 (粗分割)**: 3 类 (噪声/混凝土/金属)，钢筋+套筒合并为"金属"
2. **S2 (精分割)**: 4 类 (噪声/混凝土/钢筋/套筒)，仅修正非混凝土类别 (ignore_index=-1)

## 方法贡献

### 1. 正样本驱动的局部块采样 (Pos-balanced Patch Sampling)

训练数据加载器 `GpuCachedTrainLoader` ([lib/utils/datasets.py](file:///e:/sz-subway/precastconcrete-qc/lib/utils/datasets.py)) 的核心创新：

- **物理球查询** (R=150mm ball query) 替代纯随机全局采样，确保局部几何结构完整
- **非重叠采样** (每个点只被采样一次，最大化数据利用)
- **正样本平衡** (`pos_ratio=0.8`) — 80% 的训练 patch 包含钢筋或套筒，确保模型在少数类上有足够训练信号

消融对比：纯随机采样会导致绝大多数 patch 为纯混凝土（混凝土占 ~90% 点），模型永远看不到钢筋/套筒，分割效果大幅下降。

### 2. 级联自适应体素降采样 (Cascade with Adaptive Voxel Downsampling)

核心洞察：**混凝土占点数最多 (≈90%) 但最容易分割，钢筋/套筒占点最少 (≈2%) 但最难分割。**

```
S1 (3类)
  │
  ├─→ 预测: 噪声 / 混凝土 / 金属
  │
  └─→ 仅对混凝土做 4cm 体素降采样 ─→ S2 (4类精分割)
      噪声+金属全部保留 ✓               │
                                        ├─ ignore_index=-1 跳过混凝土
                                        └─ 最终: 混凝土继承 S1 标签, 其他取 S2 输出
```

实现位置：[lib/cascade/filter.py](file:///e:/sz-subway/precastconcrete-qc/lib/cascade/filter.py) — `filter_patch()` 函数

## 级联管线流程

```
Phase 1 (S1)                    Phase 2 (S2)
  3 类分割                       4 类精分割
噪声/混凝土/金属              噪声/混凝土/钢筋/套筒
                                │
输入: XYZ (3通道)             输入: XYZ + S1概率 (6通道)
PointNet++ 固定半径            PointNet++ 固定半径
CrossEntropyLoss               CrossEntropyLoss(ignore_index=-1)
                                │
                                ▼
                            S1 预测 → filter_patch → S2 推理
                            最终: 混凝土取 S1 标签, 其他取 S2 预测
```

## 代码架构

### 骨架模型 ([lib/backbones/](file:///e:/sz-subway/precastconcrete-qc/lib/backbones/))

四种架构统一通过 `experiments/_config.py` 的 `ARCH_REGISTRY` 注册，由 `get_backbone_cls(arch)` 工厂函数创建：

- **PointNet++** (`pointnet2.py`) — 分层 SA + FP 解码器，球邻域查询，支持自适应半径
- **PointNet** (`pointnet.py`) — MLP + 最大池化全局特征，拼接局部+全局特征
- **PointMLP** (`pointmlp.py`) — GeometricAffine (k-NN) + ResMLP 残差块
- **PointNeXt** (`pointnext.py`) — PointNet++ 改进版，可配置 feature_type

S1 使用 `S1Model` 包装器 (3类, 仅XYZ输入)；S2 使用 `Stage2Model` (继承 PointNet++, 6ch: XYZ + S1_probs)。

### 级联管线方法 ([lib/cascade/](file:///e:/sz-subway/precastconcrete-qc/lib/cascade/))

| 文件 | 核心函数/类 | 功能 |
|------|------------|------|
| `filter.py` | `filter_patch()` | S1预测→仅混凝土4cm体素降采样, 保留全部噪声+金属 |
| `stage2_model.py` | `Stage2Model` | PointNet++ (in_channels=6), 输入XYZ+S1_probs |
| `precompute.py` | `build_s2_dataset()` / `load_s2_loader()` | S1冻结推理→过滤→磁盘缓存；变长padding DataLoader |
| `validate.py` | `val_v2_simple()` / `val_s2_cached()` | 全管线V2验证 (S1实时→S2) / S2缓存版验证 |

### 数据加载器 ([lib/utils/datasets.py](file:///e:/sz-subway/precastconcrete-qc/lib/utils/datasets.py))

| 类 | 用途 | 特点 |
|----|------|------|
| `GpuCachedTrainLoader` | 训练集 | 物理球查询 + GPU缓存 + pos_ratio=0.8 + 显存打乱 |
| `RandomValDataset` | 验证/测试集 | 固定种子球查询，一次性生成不变 |
| `RandomSampleDataset` | 消融A1a | 纯随机采样，无球查询约束 |

### 训练器 ([experiments/](file:///e:/sz-subway/precastconcrete-qc/experiments/))

| 训练器 | 用途 | 特点 |
|--------|------|------|
| `_s1_trainer.py` | S1 3类分割 | 多架构支持、早停、断点续训、标签映射 (4→3) |
| `_s2_trainer.py` | S2 精分割 | S1冻结→预计算缓存→训练、变长padding、ignore_index |
| `_a2_trainer.py` | A2消融 | 单阶段4类、PointMLP骨干、无级联 |

## 实验体系

### 级联管线基线 (`--arch` CLI 支持四种骨干)

| 命令 | S1 骨干 | S2 模型 |
|------|---------|---------|
| `experiment_phase1_baseline.py` | PointNet++ (默认) | — |
| `experiment_phase1_baseline.py --arch pointnet` | PointNet | — |
| `experiment_phase1_baseline.py --arch pointmlp` | PointMLP | — |
| `experiment_phase1_baseline.py --arch pointnext` | PointNeXt | — |
| `experiment_phase2_baseline.py --arch pointnet++` | 加载对应 S1 | PointNet++ (6ch) |
| `experiment_phase2_baseline.py --arch pointnet` | 加载对应 S1 | PointNet++ (6ch) |

S2 固定为 PointNet++（6 通道输入：XYZ + S1_probs）。

### 消融实验

| 实验 | 验证模块 | 做法 | 评价指标 |
|------|---------|------|---------|
| **A1a** | 正样本局部块采样 | `RandomSampleDataset` 纯随机采样，只训 S1 | S1 mIoU |
| **A1b** | 正样本平衡 | `pos_ratio=1.0` (自然分布)，只训 S1 | S1 mIoU |
| **A2** | 级联降采样管线 | `SingleStageModel` 单阶段 4 类 (不级联) | 4 类 mIoU |

### 敏感度分析

| 实验 | 敏感参数 | 扫描范围 | 方法 |
|------|---------|---------|------|
| **S1** | 球查询半径 | 100 / 150(基线) / 200 / 300 mm | 修改 `PATCH_RADIUS_MM` 重新训练 S1 |
| **S2** | S2 体素大小 | 20 / 40(基线) / 80 mm | `train_s2_voxel()` 不同 voxel_mm |
| **S3** | 点云密度 | low / medium / high | 评估基线 cascade |
| **S4** | 噪声水平 | low / medium / high | 评估基线 cascade |
