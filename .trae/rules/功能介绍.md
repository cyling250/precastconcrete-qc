# 功能介绍

## 项目目标

从预制混凝土构件的**点云数据**出发，使用深度学习分割方法，自动将点云分类为**噪声、混凝土、钢筋**三类，支持多架构对比、分割效果可视化和定量评估。

## 支持的模型架构

| 架构 | 文件 | 特点 |
|------|------|------|
| **PointNet++** | `model.py` | 分层 SA + FP 解码器，物理球邻域查询 |
| **PointNet** | `pointnet_model.py` | 原始 PointNet，MLP + 最大池化全局特征 |
| **PointMLP** | `pointmlp_model.py` | 残差 MLP + 几何仿射变换模块 |
| **PointNeXt** | `pointnext_model.py` | PointNet++ 改进版，更优的训练策略 |

### PointNet++ 方法流程 (默认基线)

```
原始点云 (NPZ: points + labels)
  │
  ▼
1️⃣ 数据加载:
   ─ 从 augmented/ 加载 NPZ 文件
   ─ 随机采样至 8192 点
   ─ 归一化到单位球 (记录 scale)
  │
  ▼
2️⃣ PointNet++ 编码器:
   ─ SA1: FPS 512 点, 80mm 球查询, MLP[32,32,64]
   ─ SA2: FPS 128 点, 160mm 球查询, MLP[64,64,128]
   ─ SA3: 全局, MLP[128,256,512]
  │
  ▼
3️⃣ 解码器:
   ─ FP3: 距离加权插值 + 跳跃连接 → MLP[256,256]
   ─ FP2: 距离加权插值 + 跳跃连接 → MLP[128,128]
   ─ FP1: 距离加权插值 + 跳跃连接 → MLP[64,32]
  │
  ▼
4️⃣ 分类头:
   ─ Conv1D → Dropout(0.3) → Conv1D → 3 类输出
  │
  ▼
5️⃣ 输出: 每点分类概率 (噪声/混凝土/钢筋)
```

## 关键特性

- **多架构对比**: 支持 PointNet++ / PointNet / PointMLP / PointNeXt 四种架构
- **动态物理半径**: 传入 scale (mm) 将 80mm/160mm 物理半径映射到归一化空间
- **PerSampleWeightedCE**: 每样本自适应加权交叉熵，有效处理钢筋(≈2%)类别不平衡
- **随机采样**: 训练/验证统一用 8192 点随机采样，无预处理流水线
- **共享训练模块**: `_common.py` 统一管理训练/验证循环、种子设置、常量定义

## 实验体系

### 基线实验 (架构对比)
| 实验 | 模型 |
|------|------|
| `experiment_pointnet2_baseline` | PointNet++ (默认基线) |
| `experiment_pointnet_baseline` | PointNet |
| `experiment_pointmlp_baseline` | PointMLP |
| `experiment_pointnext_baseline` | PointNeXt |
| `experiment_sota_comparison` | 四种架构统一对比 |
| `experiment_benchmark_comparison` | 基准测试对比 |

### 消融实验 (A 系列)
| 实验 | 说明 |
|------|------|
| `a1_no_geo` | 去掉几何特征 (坐标/法线) |
| `a2_fixed_ce` | 固定交叉熵权重 (代替每样本自适应加权) |
| `a3a_noise_ignore` | 训练时忽略噪声类 |
| `a3b_noise_equal` | 噪声类与其他类等权重 |
| `a4_no_filter` | 不对点云做任何过滤 |

### 鲁棒性实验 (S 系列)
| 实验 | 说明 |
|------|------|
| `s1_patch_radius` | 改变 PointNet++ 球查询半径 |
| `s3_density` | 改变点云采样密度 |
| `s4_noise` | 改变噪声水平 |

### 默认实验配置

| 参数 | 默认值 |
|------|--------|
| 每样本点数 | 8192 |
| Batch size | 8 |
| 优化器 | AdamW (lr=5e-4, wd=1e-4) |
| 学习率调度 | Cosine Annealing |
| 训练轮数 | 80 |
| SA1 半径 | 80mm (物理) |
| SA2 半径 | 160mm (物理) |
| 损失函数 | PerSampleWeightedCE |
