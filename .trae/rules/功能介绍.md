# 功能介绍

## 项目目标

从预制混凝土构件的**点云数据**（.ply 格式）出发，自动完成：
1. **点云分类** — 区分混凝土与钢筋区域
2. **几何拟合** — 用 RANSAC 拟合平面（混凝土面）和直线（钢筋）
3. **拓扑重建** — 构建混凝土封闭实体 + 钢筋圆柱体，输出网格文件

## 流程概览

```
点云(.ply)
  │
  ▼
1️⃣ 预处理: 高斯噪声 → 体素下采样
  │
  ▼
2️⃣ 邻域特征计算 (11维特征: 线性度/平面度/球度...)
  │
  ▼
3️⃣ K-means 聚类 (特征加权)
  │
  ▼
4️⃣ 混凝土拟合 (RansacPlaneFitter, 最多6个平面)
  │
  ▼
5️⃣ 钢筋拟合 (RansacLineFitter, 线性度阈值筛选)
  │
  ▼
6️⃣ 混凝土三维重建:
   ─ 平面交线 → 线段交点 → pygmsh 面环 → 体网格
  │
  ▼
7️⃣ 钢筋三维重建:
   ─ 钢筋参数 → pygmsh 圆柱体 → 合并网格
  │
  ▼
8️⃣ 输出: mesh-concrete.vtk + mesh-rebar.vtk
```

## 关键参数 (main.py)

| 参数 | 默认值 | 说明 |
|------|--------|------|
| NEIBOR_DISTANCE | 40 | 邻域搜索半径 (mm) |
| FEATURE_WEIGHTS[3,4] | 5.0, 5.0 | 线性度/平面度权重最高 |
| CONCRETE_THRESHOLD | 0.005 | 平面内点距离阈值 |
| CONCRETE_MAX_PLANE_NUM | 6 | 最多拟合平面数 |
| REBAR_LINEARITY_THRESHOLD | 0.1 | 钢筋线性度筛选阈值 |

## 输入/输出

- **输入**: `.ply` 格式点云文件
- **中间产物**: 聚类结果 `.ply`、平面/直线参数 `.npy`、内点点云 `.ply`
- **输出**:
  - `mesh-concrete.vtk` — 混凝土三维体网格
  - `mesh-rebar.vtk` — 钢筋三维网格
