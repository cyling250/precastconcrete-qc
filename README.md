## 项目简介

预制混凝土构件三维拓扑重建系统是一个专注于**点云数据处理**和**几何拓扑分析**的专业工具。本项目已完成开发，能够对预制混凝土构件的点云数据进行精确的三维拓扑重建，自动识别构件的几何特征和拓扑关系，为构件数字化建模和BIM应用提供核心技术支持。

## 项目背景

在建筑工业化进程中，预制混凝土构件的数字化建模是BIM技术应用的关键环节。传统的构件建模方法依赖人工操作，效率低下且难以保证几何精度。本项目通过开发自动化的三维拓扑重建算法，实现了从点云数据到构件几何模型的智能转换，为预制构件的数字化管理提供技术支撑。

## 主要功能

### ✅ 已完成功能

- **点云数据处理**：完整的点云加载、滤波、下采样等预处理流程
- **特征提取与聚类**：基于邻域特征的点云智能分类，识别构件不同几何特征
- **几何特征拟合**：使用RANSAC算法精确拟合构件的平面、直线等几何元素
- **拓扑关系识别**：自动分析构件各几何元素之间的空间关系和连接性
- **三维拓扑重建**：基于几何拟合结果重建构件的完整拓扑结构
- **数据导出**：支持多种格式的拓扑数据导出，便于后续BIM应用

## 核心技术

### 算法架构

本项目采用模块化架构设计，专注于三维拓扑重建，主要包括以下几个核心模块：

1. **数据预处理模块**：

   - 点云数据加载和格式转换
   - 噪声滤波和体素下采样
   - 邻域特征计算和特征权重配置
2. **几何特征提取模块**：

   - 基于K-means的点云聚类
   - 构件几何特征的自动识别
   - 特征权重优化的分类算法
3. **几何拟合模块**：

   - RANSAC平面拟合算法
   - 线性度检测的直线拟合
   - 多几何元素的并行处理
4. **拓扑重建模块**：

   - 基于拟合结果的拓扑关系分析
   - 几何元素连接性自动识别
   - 拓扑结构完整性验证
5. **数据输出模块**：

   - 拓扑数据格式转换
   - BIM兼容数据导出
   - 重建结果质量评估

### 技术特点

- **高精度**：采用RANSAC算法确保几何拟合的准确性
- **智能化**：基于机器学习的自动特征识别
- **模块化**：清晰的模块划分，便于维护和扩展
- **跨平台**：支持Windows和Linux操作系统

## 安装教程

### 系统要求

- Windows 10/11 64位操作系统 或 Linux发行版（Ubuntu 18.04+，CentOS 7+）
- Python 3.8及以上版本
- 8GB以上内存（推荐16GB）
- 无需专用显卡，支持CPU计算

### 环境配置

1. **安装Python依赖**：

   ```bash
   pip install open3d numpy pygmsh pyvista
   ```
2. **下载测试资源**（可选）：
   从项目资源库下载测试点云文件，放置在 `mock/res/point/` 目录下
3. **验证安装**：

   ```bash
   python debug.py
   ```

## 使用说明

### 快速开始

1. **准备点云数据**：
   将预制构件的点云文件（.ply格式）放置在指定目录

2. **运行拓扑重建程序**：
   ```bash
   python main.py --input mock/res/point/prefabricated_laminated_beam.ply --output output
   ```

3. **查看重建结果**：
   程序将生成以下输出文件：
   - 几何特征拟合参数
   - 拓扑关系数据
   - 三维拓扑结构文件
   - 重建质量评估报告

### 参数配置

项目支持丰富的参数配置，可通过命令行参数或配置文件进行调整：

```bash
python main.py
```
