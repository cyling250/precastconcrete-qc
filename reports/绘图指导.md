## 3. 绘图脚本骨架

技能提供的样式模块在 `C:\Users\35160\.zcode\skills\scientific-plotting\scripts\sci_style.py`，**不要手写 rcParams**。

```python

sys.path.insert(0, r"E:\pc-seg\precastconcrete-qc")

import sci_style as ss
import numpy as np

ss.apply_style()
fig, ax = ss.new_figure()               # 70x50 mm，越界会报错

t   = np.arange(0.0, 1.01, 0.1)
geo = np.array([0.707,0.676,0.604,0.579,0.531,0.473,0.413,0.335,0.266,0.227,0.159])
net = np.array([...])                   # 修正测试集后重跑得到的 11 档结果
```
